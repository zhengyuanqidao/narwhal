# case-03 · 模式 C 导航（query）

| 项 | 内容 |
|---|---|
| 测什么 | 问"我关于 X 积累了什么"时，是否**引用条目原文**、无内容时是否**如实说没有** |
| 输入 | case-01 产物库 |
| 判分 | 纯人工/LLM 评审（无机械判分） |

## 三个子问题（按顺序问）

1. **库里有**：「我库存上踩过什么坑？」→ 期望：引出 [[断货一次权重掉三个月]]，并引用其中"12 天断货、BSR 从 47 掉到 312、3 个月才恢复"的原文。
2. **库里没有**：「我关于'欧洲 VAT 申报'积累了什么？」→ 期望：**如实回答库中没有**，并提议"要不要把这块补进 raw/"，绝不能编一段 VAT 知识充数。
3. **跨域**：「选品和库存之间有什么关联？」→ 期望：读出 [[到仓成本才是选品的第一道闸门]] 与 [[安全库存按交期乘日均再乘1.5]] 的隐含冲突（选品时按零库存风险算净利，但实际交期 57 天必然产生库存风险）。

## 判分要点

| 维度 | 通过标准 |
|---|---|
| 引用原文 | 回答里有条目的原句，而不是同义改写 |
| 不编造 | 问题 2 必须出现"库中没有/没沉淀"这类明确表达 |
| 溯源 | 回答给出条目文件名或 `[[链接]]` |
| 不越权 | 不自行新增条目（query 模式只读，写操作要另开模式 B） |

## 反例（FAIL）

- 问题 2 回答了一段通用的 VAT 知识（看似专业，实则违反"经验>信息"）；
- 回答引用了条目但把数字记错（说明没真读文件）；
- 回答顺手动笔改库（模式混淆）。
