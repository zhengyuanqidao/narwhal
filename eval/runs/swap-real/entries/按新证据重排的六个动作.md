# 按新证据重排的六个动作

**一句话结论**：排顺序的唯一依据是"哪一条不解决，后面的都白做"，不是"哪一条最容易做"。

## 展开

新证据落定后，我把动作重排成六步：第一，定价主表定稿，全部付费资产首发 ¥9–29，用真实成交验证，涨价留到有 ≥10 单和好评之后；第二，首个付费资产换选型，从"编译师（通用、撞赛道）"改成一个具体垂直场景的经验封装，判据是 Askpert 四条——周期性复现、一下午能验收、输出无需卖家在场、编码了通用模型拿不到的私人材料；第三，移除体检官，不重设计；第四，企业认证 + 签约仍是最前置动作，过审后先上免费技能解锁收费资格；第五，¥1 探针改为先试 SkillPay 按次（见 [[SkillPay按次比买断更适合探针]]），若平台尚未对个人开放，退回 ¥1 买断，只验三件事；第六，竞品表仍需人肉填 20 行。

第六步最容易被忽略，也最不能外包：这份情报全是网络侧的，客户端里的真实价格与销量只有本人能看到。它看起来最不"技术"、最像杂活，但它决定了前五步的前提是否成立——如果真实价格带根本不是 ¥9，前面五步全部要重排。

## 适用边界 / 反例

反例是我原来的排序：把"矩阵设计""多产品线""跨平台"排在前面，把"认证 + 提交"排在后面，结果做了大量规划却没有一次真实提交。另一个边界：这六步里只有第 4 步卡在外部（企业认证审核），其余五步都不依赖任何人，所以"等审核"不能成为不动手的理由——审核的 24 小时正好用来填竞品表。

⭐ 一句话给三年后的自己：顺序错了，努力会变成反向的利息。
