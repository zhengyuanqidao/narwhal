# Askpert四问筛选垂直场景

**一句话结论**：选第一个付费垂直场景时，用四条硬标准卡住，避免凭"我熟悉"就开工。

## 展开

确定"付费资产必须转向具体垂直场景"后，问题是选哪个。我把 Askpert 的四条标准写成选型闸门：①周期性复现——不是一次性任务，用户会反复用；②一下午能验收——交付周期短，能快速拿到反馈；③输出无需卖家在场——买家自己就能跑出结果，不依赖我陪跑；④encodes 通用模型拿不到的私人材料——内部政策、判例、领域规则、运营数据。四条同时满足才算候选。这四条正好把"我熟悉的领域"和"能卖钱的领域"区分开：熟悉是必要条件，但只有满足四问才是可封装资产。我的操作是拿 eval 里现成的跨境/直播电商/私域语料逐一过这四问，过关的那个才建资产目录。

## 适用边界 / 反例

四问是筛选器不是保证书。过了四问仍可能没人买——市场验证是另一道门（见[[上架不等于成交]]）。另外第④条"私人材料"要求用户提供真实内部资料，若用户拿不出来，这个场景就退化成通用工具，要重新选。

⭐ 一句话给三年后的自己：熟悉只是入场券，四问过了才值得封装。
