# 选品复盘：宠物饮水机（2025-08）

> 模拟素材（eval fixture），模拟一位亚马逊卖家的散落文档。

## 背景

7 月看中宠物饮水机类目，头部 3 家月销 3000+，单价 39.99。我的直觉是"宠物 + 刚需 + 复购滤芯"，想直接上。

## 我实际算的账

采购价 68 元/台看着有 45% 毛利，但我把到仓成本摊开：

| 项 | 金额（元/台） |
|---|---|
| 采购价 | 68 |
| 头程海运（分摊） | 11 |
| 关税+清关 | 6 |
| 亚马逊佣金 15% | 40 |
| FBA 配送费 | 33 |
| 到仓总成本 | 158 |
| 售价 39.99 美元 ≈ 288 元 | |
| 毛利率 | **(288-158)/288 = 45%** |

但这是**按 0 退货、0 广告**算的。加两项就崩了：

- 该类目退货率 8%，退货处理 + 不可售损耗摊 9 元/台；
- 新品期广告 ACOS 55%，广告成本摊 40 元/台；
- 结果真实净利 ≈ 20 元/台，净利率 7%。

## 结论

我最后没上这个款。原因不是毛利低，是**7% 的净利率承受不住一次断货或一次广告失控**。后来换了一个到仓成本占比更低的款（采购价 42 元，到仓 118 元），净利率 14%，才敢推。

教训：选品第一件事是算到仓成本，采购价只是其中一项；第二件事是按"退货 + 广告"压力测试净利。
