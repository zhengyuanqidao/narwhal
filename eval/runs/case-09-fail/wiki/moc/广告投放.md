# 广告投放 知识地图（MOC）

> 这一领域我沉淀了什么、它们之间什么关系。新条目入库后挂到这里。

## 核心问题

ACOS 涨了，到底该动哪里？哪些广告花费是"没有广告就不会发生的成交"，哪些只是在给自己交税？

## 知识结构

### 基础概念 / 洞察
- [[ACOS飙升先查转化率不是先改出价]] — 归因顺序 CVR → CTR → CPC → 出价；只有走到第三步才调价。

### 踩坑与教训
- [[品牌词广告是给自己交税]] — 品牌词自然排名稳定时，SB 品牌词组 ACOS 57% 纯属自税，关掉不影响排名。

## 知识关系

```
ACOS 归因（洞察·方法层）
  └─ 推论 → 品牌词自税（踩坑：属于"归因错位"的一种）
```

## 待深潜

- 竞品词广告的 ACOS 目标该怎么定？现在只有品牌词和核心词的判断，竞品词没有标准。
- 降低 ACOS 之后，利润是否同步上升？W38 那次 ACOS 降了 7 个点，但没跟踪净利变化（已进 OPEN-QUESTIONS）。
