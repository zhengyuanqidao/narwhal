# 到仓成本才是选品的第一道闸门

**一句话结论**：选品时看采购价算毛利是自欺，必须先把到仓成本叠加齐（采购 + 头程 + 关税 + 佣金 + FBA + 退货损耗），再用"退货 + 广告"做压力测试，剩下的净利才是真净利。

## 展开

我差点上了宠物饮水机：采购价 68 元、卖 39.99 美元（约 288 元），账面毛利 45%，看着能打。把到仓成本摊开才发现：头程 11、关税 6、佣金 40、FBA 33、退货损耗 9、新品期广告摊 40——到仓 158 元，再扣退货与广告，真实净利只有 20 元/台，净利率 7%。

我当时改了两个判断：一是把"毛利率"从决策指标里删掉，只留净利率；二是给净利率设一条硬线——低于 12% 的款不推，因为 7% 的净利承受不住一次断货或一次广告失控（后来 10 月真的断货一次，验证了这条线）。最终换了一款到仓 118 元、净利率 14% 的款，就是后来跑起来的那款。

一个容易被忽略的点：**广告成本不是选品后才有的成本，它在选品阶段就该被估进去**。新品期 ACOS 45~55% 是常态，按 0 广告费算净利，等于在预算里藏了一个必炸的坑。

## 适用边界 / 反例

- 适用于自有库存 + 海运头程的模式（FBA/海外仓）。
- 反例：轻小件、空运补货的快反模式，头程占比低但变动大，应按"最坏头程"算，而不是平均。
- 另一个反例：把关税按 HS 编码的税率上限算，会误杀一批本来能做的款——税率要按实际申报口径取。

⭐ 一句话给三年后的自己：毛利率是给投资人看的，净利率是决定你能活多久的。
