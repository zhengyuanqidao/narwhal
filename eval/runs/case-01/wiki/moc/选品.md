# 选品 知识地图（MOC）

> 这一领域我沉淀了什么、它们之间什么关系。新条目入库后挂到这里。

## 核心问题

怎么在现金有限、交期 57 天的约束下，选出一个"净利扛得住一次事故"的款，并在三周内判断它行不行？

## 知识结构

### 基础概念
- [[到仓成本才是选品的第一道闸门]] — 采购价只是到仓成本的一项；净利要按"退货 + 广告"压力测试，净利率 <12% 不立项。

### 方法与 SOP
- [[小批量测款三周就能判生死]] — T+21 三条线处置（≥15 单加投 / 5~15 单改图 / <5 单清货）。

### 经验案例
- [[宠物饮水机90天从日销3单到80单]] — 先毙掉 7% 净利的款，换 14% 的款，90 天做到日销 80。

## 知识关系

```
到仓成本（概念·闸门）
  ├─ 决定 → 测款三条线（方法：只有过了闸门的款才值得测）
  └─ 被验证 → 宠物饮水机 90 天（案例：毙掉第一个方案是关键动作）
```
