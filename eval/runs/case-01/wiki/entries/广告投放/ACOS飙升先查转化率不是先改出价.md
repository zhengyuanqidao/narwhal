# ACOS飙升先查转化率不是先改出价

**一句话结论**：同一批词、同一批出价，ACOS 从 28% 涨到 31%，原因是 CVR 掉了 0.5 个点，不是广告投坏了——先去查 listing，别动出价。

## 展开

W38 周报里我写了原话："ACOS 升到 31%，不是广告投坏了，是 listing 转化率掉了。同一批词、同一批出价，CPC 只涨了 3%，但 CVR 掉了。先别动出价，去查主图是不是被竞品比下去了。"

这个归因顺序很关键，因为两种错误的成本完全不同：

- **误判成广告问题** → 降出价/关词 → 曝光掉 → 销量掉 → 排名掉，问题反而放大；
- **正确定为 listing 问题** → 换主图/改 A+ → 3~7 天见效，广告结构不用动。

我现在的固定排查顺序是：CVR → 点击率 → CPC → 出价。CVR 掉通常是主图/价格/竞品降价/差评；点击率掉是主图或标题；CPC 涨才是竞价环境变了。**只有走到第三步，才轮到调出价。**

顺带一条：ACOS 目标不该拍脑袋定 30%，要按毛利率反算——毛利率 40%、目标广告占比 15%，则目标 ACOS = 26.7%。目标定错了，后面所有优化都是在错误方向上努力。

## 适用边界 / 反例

- 适用：成熟期、词包稳定的广告组，用来做归因。
- 反例：新品期 CVR 天然低（没评价），此时 ACOS 高是正常的，按"先查 CVR"会白折腾——新品期该看曝光与点击率。
- 反例：竞品集体降价时，CVR 掉是外部原因，改主图没用，这时候确实要动价格或等。

⭐ 一句话给三年后的自己：ACOS 是仪表盘上的灯，CVR 才是发动机。
