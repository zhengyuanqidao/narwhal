# 只看GMV会掩盖退货黑洞

**一句话结论**：服饰类目必须按"签收口径"算账，否则 GMV 越漂亮，亏得越安静。

## 展开

10-19 那场，战报写着 GMV 58 万，团队在群里发红包庆祝。我把财务口径拉出来：

| 口径 | 金额 |
|---|---|
| GMV（下单口径） | 58 万 |
| 退货率（预估 62%） | -36 万 |
| 签收口径收入 | 22 万 |
| 毛利（38%） | 8.4 万 |
| 投流 | -9 万 |
| 坑位费 | -2 万 |
| 主播佣金 | -6 万 |
| **净利** | **-4.6 万** |

一场"爆场"，实际净亏 4 万多。问题不在卖得少，在**退货率被当成了售后问题，而不是选品问题**。

我的判断：退货率 60% 以上时，退货原因基本不是"不合适"，而是"和预期不符"——主播话术夸大、滤镜过度、尺码建议不准。这三个都是可以在开播前控制的。所以我把退货率拆到 SKU 维度，找出退货最高的 3 个款，下次直接不上。

配套动作：给每个 SKU 标注"历史退货率"，排品表里退货率 >55% 的款，除非毛利 >55%，否则不进主推位。这条规则上了之后，下一场退货率降到 44%，净利转正。

## 适用边界 / 反例

- 适用：服饰、鞋包、珠宝等"预期差"大的类目。
- 弱适用：标品/3C，退货率天然低（<10%），GMV 口径误差不大，不必上这套重核算。
- 反例：为压退货率把尺码建议写得极其保守（"建议买大两码"），退货降了但换货率飙升，履约成本更高。

⭐ 一句话给三年后的自己：战报看 GMV，决策看签收口径的净利。
